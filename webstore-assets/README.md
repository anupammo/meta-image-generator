# Chrome Web Store Assets

This folder contains upload-ready Chrome Web Store listing assets for Meta Image Generator.

Files included here:

- `promo-small-440x280.png` - required small promotional image
- `promo-marquee-1400x560.png` - optional marquee promotional image
- `screenshot-01-overview-1280x800.jpg` - store screenshot
- `screenshot-02-audit-1280x800.jpg` - store screenshot
- `screenshot-03-generator-1280x800.jpg` - store screenshot
- `asset-manifest.json` - generated file list and timestamp
- `review-disclosures.md` - copy for the Chrome Web Store privacy and permission form
- `privacy-policy.html` - publishable privacy policy page for the extension

Chrome Web Store image sizes used:

- Small promo: 440 x 280
- Marquee promo: 1400 x 560
- Screenshots: 1280 x 800
