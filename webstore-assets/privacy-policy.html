Privacy Policy

Meta Image Generator Chrome Extension

Last updated: April 8, 2026

Overview

Meta Image Generator checks the social preview metadata of the active webpage and generates a downloadable social preview image in the browser.

What Data The Extension Accesses

When you open the extension on a webpage, it reads page data locally in your browser to perform its function. This can include:

  • Open Graph and Twitter Card meta tags
  • Page title and meta description
  • Canonical URL and domain name
  • Favicon, logo candidates, and related page image references
  • Basic visual styling hints such as theme color or detected page colors
  • An optional direct image URL that you provide for rendering a preview image

What The Extension Does Not Do

Meta Image Generator does not collect, store, or transmit personal data or browsing data to the developer or third parties.

  • It does not create user accounts.
  • It does not use analytics or advertising trackers.
  • It does not sell or share user data.
  • It does not monitor browsing activity in the background.
  • It does not use remote code execution.

How Image Rendering Works

Image generation happens locally on your device using browser APIs. Downloaded files are created locally in your browser. If you choose to use an external image URL, your browser may request that image directly from the source so it can be rendered in the generated preview.

Permissions

The extension uses activeTab, scripting, and host access only to inspect the page you choose to analyze, extract its social metadata, and fetch image assets needed for preview or local image generation.
