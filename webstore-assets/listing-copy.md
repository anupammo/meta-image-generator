# Chrome Web Store Listing Copy

## Short Description

Check meta image availability and generate brand-aware OG images from the active page.

## Detailed Description

Meta Image Generator helps you inspect a page's social preview setup and create polished replacement assets without leaving the browser.

Use it to:

- Check whether the active page already has an `og:image` or `twitter:image`
- Review Open Graph, Twitter Card, canonical, and description metadata in one popup
- Audit common social preview requirements for platforms like Facebook, LinkedIn, and X
- Detect page color hints, logo candidates, and brand signals automatically
- Generate new social preview images with multiple layouts, templates, and export formats
- Download generated assets as PNG, JPG, or WebP

Best for marketers, SEO workflows, content teams, and developers who want a faster way to validate and produce social preview images.
